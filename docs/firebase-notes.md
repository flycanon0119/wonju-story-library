# Firebase 개발 기록

## 현재 연결

- 기존 앱은 Firebase Authentication의 이메일 로그인·인증과 Firestore에 연결되어 있습니다.
- 브라우저에는 웹앱용 설정만 사용합니다. 서비스 계정 키나 관리자 비밀키를 넣지 않습니다.
- GitHub에는 설정 예시만 올리고, 실제 `dist/firebase-config.js`는 제외합니다.
- 접근 권한은 `firestore.rules`와 로그인 상태로 제한합니다. 개인정보를 화면에서 가리는 것만으로 데이터 접근을 막을 수는 없습니다.

## 2026-10-26: 개인 활동 책갈피

- 완료한 멘토링에 연결해 ‘오늘 얻은 힌트’와 ‘다음에 해보고 싶은 활동’을 기록합니다.
- 개인 기록은 기존 `users/{uid}/notes/{meetingId}`에 저장하며 본인만 읽습니다.
- 해당 사람책과 ‘내 공간’에서 다시 읽고 수정합니다.
- 개인 활동 기록과 공개 후기를 분리합니다. 공개 여부는 별도로 동의합니다.
- 개인 기록과 후기는 Firestore 일괄 쓰기로 함께 저장합니다. 저장 실패 시 완료로 표시하지 않습니다.
- 기록 연결, 계정별 분리, 비공개·공개 데이터 분리, 저장 실패와 계정 전환을 자동 검증했습니다.

## 검증 범위

자동 검증은 모의 Firestore를 사용합니다. 실제 사용자 계정으로 완료된 멘토링을 생성해 저장·수정하는 종단 간 검증은 아직 하지 않았습니다. 실제 청소년 모집 전에 계정 인증, 멘토 승인과 운영자 신고 대응도 확인해야 합니다.

## 이후 Firebase 학습 시 원칙

첨부된 학습 프롬프트에 따라 현재 구조를 먼저 확인하고, 개념 → 적용 → 실행 → 확인 순서로 작은 단계를 진행합니다. 새로운 실습은 Emulator를 우선 사용합니다. 실제 프로젝트 변경이나 유료 기능 도입은 범위를 확인한 뒤 진행합니다.
