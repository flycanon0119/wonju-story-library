# 형상관리 안내

## 저장소

- GitHub: https://github.com/flycanon0119/wonju-story-library
- 공개 범위: 공개. 누구나 링크로 코드를 볼 수 있으며, 직접 수정 권한은 소유자와 쓰기 권한을 받은 협업자에게만 있습니다.
- 기존 배포용 Git 이력은 원본 앱 폴더에 보존합니다.
- GitHub의 첫 등록본은 실제 설정값과 배포용 메타데이터를 제외한 앱 소스입니다. 이전 배포 이력을 통째로 올리지 않습니다.

## 변경 작업

1. 작은 기능이나 수정 단위로 작업하고 변경 이유를 커밋에 남깁니다.
2. JavaScript 문법과 관련 기능을 확인합니다. 활동 기록 변경 시 `node tests/activity-bookmarks.test.cjs`를 실행합니다.
3. 회원 데이터·비밀번호·관리자 키·실제 설정 파일이 포함되지 않았는지 확인합니다.
4. GitHub의 최신 `main`을 확인한 뒤 변경 파일을 추가 커밋으로 반영합니다. 기존 이력을 강제로 덮어쓰지 않습니다.
5. 앱 공개 반영은 별도 배포 단계로 진행합니다. GitHub에 코드를 올렸다고 앱이 자동 배포되지는 않습니다.

기존 배포용 저장소의 전체 이력을 GitHub에 직접 밀어 넣으면 과거 설정 파일도 포함될 수 있으므로 주의합니다. 코드 열람은 저장소 링크를 공유하면 됩니다. 함께 코드를 수정할 팀원을 초대하려면 저장소 Settings → Collaborators에서 팀원의 GitHub 계정을 추가합니다.
